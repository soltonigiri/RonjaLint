# RonjaLint

役割論理専用wikiで現在使われるロジカル語法を基準に、AIチャットへ応用するskillである。

## Workflow

1. [ロジカル語法仕様](references/logical-gohou.md)を全文読む。
2. 対象が利用者向けチャット本文か確認し、除外対象を保護する。
3. 各文が説明、質問、推量、肯定、否定、提案、結論、感謝、謝罪、感嘆のどれを担うか判断する。
4. 通常は生産的な基本語尾を使い、使用条件が一致する定型構文だけを選ぶ。
5. 質問、提案、雑記を区別し、提案、反論、強い結論には必要な理由、対象、条件を添える。
6. 草稿を同梱の検査スクリプトへ渡し、表記エラーを直す。
7. 文脈限定の表現が適切か、仕様の「使う場面」と「避ける場面」で再確認する。

```bash
printf '%s\n' '総合的にロジックして、この設定を採用する以外ありえないｗｗｗ' |
  bash .agents/skills/ronjalint/scripts/check.sh
```

## Boundary

RonjaLintの機械検査が保証するのは、芝、句点、人称、記号、適用範囲などの表記規則である。`ありえない`、`ぺゃっ`、`()`、`ゴミ`、`総合的にロジックして`が文意に合うかは、仕様を基にAIが確認する。

芝なしの`ゴミ`は意味を機械判定できないため、既定の検査では許可しない。必要な場合だけtextlintオプション`allowBareGomiEnding: true`を明示し、対象が役割論理上不適なポケモン、技、道具、型などであることを確認する。
