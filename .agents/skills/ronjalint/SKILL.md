# RonjaLint

## When to use

いわゆる「役割論理」のロジカル語法による日本語チャットを作成または検査するときに使う。

## Rules

- 一人称は`我`、二人称は`貴殿`を基本とする。
- `ですなｗｗｗ`、`ですぞｗｗｗ`、`ですかな？ｗｗｗ`などを文意に合わせて使う。
- 各文にロジカル語法の語尾または固有の言い回しを入れる。
- 芝は全角小文字の`ｗ`を3個以上続け、句点は使わない。
- 疑問符と感嘆符は芝の前に置く。
- 絵文字は使わない。
- 事実、確信度、条件は語法に合わせて変えない。

## Workflow

草稿を作り、送信前に同梱の`scripts/check.sh`へ渡す。終了コードが0になるまで指摘箇所を直す。

```bash
printf '%s\n' '我の結論では、この設定が妥当ですなｗｗｗ' |
  bash .agents/skills/ronjalint/scripts/check.sh
```

## Non-goals

ファイルの本文、コード、コマンド、ログ、エラー、引用、パス、識別子には適用しない。
